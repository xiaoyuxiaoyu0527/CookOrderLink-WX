# CookOrderLink 菜谱百科重设计

## 概述

将 CookOrderLink 从「库存管理+点菜」模式简化为「菜谱百科+点菜」模式。删除库存管理功能，专注于菜谱浏览、点菜、做菜教程。

## 核心变化

### 删除的功能
- 库存管理模块（inventory 集合、库存页面、库存扣减逻辑）
- 过期提醒功能
- 库存相关的云函数（updateInventoryStatus, checkExpiringInventory）

### 保留的功能
- 家庭组管理（创建/加入）
- 用户角色（烹饪者/点菜者）
- 订单系统（简化版）

### 新增的功能
- 菜谱百科（预置+手动添加）
- B站/小红书教程链接
- 添加菜谱页面

## 页面结构

| 页面 | 路径 | 说明 |
|------|------|------|
| 点菜页 | pages/order/order | 菜谱列表，选择想吃的菜 |
| 厨房页 | pages/kitchen/kitchen | 订单列表，点击进入菜谱详情 |
| 菜谱详情 | pages/recipe/detail | 食材清单+步骤+教程+小贴士 |
| 添加菜谱 | pages/recipe/add | 手动添加新菜谱 |
| 我的 | pages/profile/profile | 账号信息、退出家庭 |

## 页面设计

### 点菜页

- 菜谱卡片列表（暖色调设计）
- 支持按分类筛选（家常菜、荤菜、素菜、汤品、主食）
- 支持搜索
- 选择菜品后可添加备注
- 提交订单按钮

### 厨房页

- 订单列表（待做/已完成）
- 点击订单查看菜品列表
- 点击菜品进入菜谱详情
- 订单状态管理（待做→已完成）

### 菜谱详情页

**顶部区域：**
- 菜品名称
- 分类标签
- 难度和时间

**食材清单：**
- 列表显示食材名称和用量
- 提示「需要购买的材料」

**制作步骤：**
- 分步骤显示
- 每步可有小贴士

**教程区域：**
- 平台图标（B站🔴 / 小红书📕）
- 教程标题
- 点击跳转到对应平台

**底部操作：**
- 返回按钮

### 添加菜谱页

**基本信息：**
- 菜品名称（必填）
- 描述
- 分类选择
- 难度选择
- 预计时间

**食材清单：**
- 动态添加食材行
- 每行：名称 + 用量 + 单位

**制作步骤：**
- 动态添加步骤
- 每步：描述 + 小贴士（可选）

**教程链接：**
- 选择平台（B站/小红书）
- 填写链接
- 填写标题
- 可添加多个教程

## 云函数

### createOrder

创建订单，简化版（不检查库存）：
- 校验用户 familyId
- 校验菜品是否存在
- 创建订单
- 通知厨房端

### updateOrderStatus

更新订单状态：
- pending → done
- 校验 familyId
